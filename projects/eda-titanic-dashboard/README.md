# Interactive Titanic Dashboard - Streamlit + Plotly

## Overview
An interactive web dashboard for exploring the Titanic dataset using `streamlit` and `plotly`.

## Tools & Libraries Used
| Tool/Library | Purpose |
|---|---|
| streamlit | Interactive web app framework |
| plotly / dash | Interactive visualizations |

## How to Run
```bash
pip install streamlit plotly pandas numpy seaborn
streamlit run dashboard_titanic.py
```

## Features
- Filter by passenger class, gender, age range
- Dynamic charts that update on filter changes
- Summary statistics panel
- Downloadable data table
