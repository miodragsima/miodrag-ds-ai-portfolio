# Data Structures and Algorithms Portfolio

This repository contains simple implementations of fundamental data structures and algorithms for educational purposes. All code is written in C and designed to demonstrate basic concepts clearly, making it suitable for students learning computer science fundamentals.

### Folder Structure

```text
da110-data-structures/
├── arrays/

├── queues/
│   └── main.c
├── trees/
│   └── main.c

│   └── main.c
├── searching/
│   └── main.c
└── README.md
```
## Projects Included

### 1. Arrays Implementation
A simple demonstration of arrays in C including:
- Declaring and initializing arrays
- Accessing individual elements
- Updating array values
- Calculating sum of elements

### 2. Singly Linked List
Implementation of a singly linked list with basic operations:
- Insertion at beginning, end, and specific position
- Deletion at beginning, end, and specific position
- Searching for elements
- Displaying the list

### 3. Stacks
Implementation of stack data structure using:
- Array-based stack
- Linked list stack
- Operations: push, pop, peek

### 4. Queues
Implementation of queue data structure using:
- Simple queue
- Circular queue
- Basic operations

### 5. Trees
Implementation of binary tree with:
- Tree traversal methods:
- Inorder
- Preorder
- Postorder

### 6. Sorting Algorithms
Implementation of basic sorting algorithms:
- Bubble Sort
- Selection Sort
- Insertion Sort

### 7. Searching Algorithms
Implementation of basic searching algorithms:
- Linear search
- Binary search
